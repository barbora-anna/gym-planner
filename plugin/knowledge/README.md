# Knowledge: the why behind your decisions

The evidence base you plan from. Every training claim cites its research. Where no study
exists, the text says so plainly ("untested", "a convention", "no study tested…"): use
those as defaults and let the lifter's log override them. Practical constraints (the plates
they own, a bar's weight) aren't training claims and carry no citation.

## The short version

1. Loads come from the lifter's recent sets through `gym calc`. An e1RM is a model
   estimate shown as a range. Without RIR it's a floor (the real max is at least this).
2. Every exercise gets warm-ups (when the ramp table calls for them), then straight working
   sets at one load. Each set at one load is harder than the last, so later sets print an
   honest target (`6 @2`, then `5–6 @1–2`), never a copy of set 1. No back-offs by default:
   no trial tests them against straight sets (`loads.md`).
3. Start from the lifter's usual scheme. Otherwise, main lifts for an intermediate or
   advanced lifter's strength goal use 3–6 reps; other compounds 6–10, isolation 10–15;
   novices 6–10 / 10–15. RIR 2 (1 allowed on the session's first lift).
4. Progress load first where `gym calc` is valid (reps + RIR ≤ ~10): same reps, one step up
   when `gym calc rir` says the step fits; add reps only when the step is too big. Above
   that, or with no e1RM, double progression. A grind holds the load.
5. Count hard sets (working sets at RIR ≤ 3), not tonnage. About 10–20 per directly
   trained muscle per week, judged against the lifter's level and recovery.
6. Heavy and skill-demanding lifts go first. One true max effort per session at most.
7. Novices gain fastest and need a smaller dose, with no need for near-max work or failure.
   Judge their progress on completed reps first, since their RIR is weaker evidence
   (`progression.md`).
